# Prompts de arte para o site (série completa, versão 26)

**Como usar**
1. Abra **um chat novo** no ChatGPT só para as artes do site e use sempre o mesmo. Ele mantém o traço.
2. Cole primeiro a **Mensagem 0** abaixo (uma vez só).
3. Depois cole **um prompt por vez**. Peça o tamanho indicado em cada um.
4. Mande a imagem para o Claude neste chat dizendo o código (ex.: "B1"). Ele recorta e põe no site. Os que dizem "você mesmo põe" não precisam passar por ele.

**Ordem que eu sugiro** (do que mais aparece para o que menos aparece): A3, A1, B1, B2, B3, B4, A4, C4, C1, C2, B5, B6, B7, B8, A2, C3, E1, D1, D2, C5, C6, A5, E2.

**Conferir antes de mandar** (se falhar, peça de novo no mesmo chat citando só o defeito)
- Folha: tem o número certo de casas? Alguma casa encostou na outra ou foi cortada?
- Fundo rosa (#FF00FF) liso, sem sombra? Tem rosa dentro do desenho?
- Tem letra ou número desenhado? (não pode)
- Ficou parecido com personagem que existe? Peça: "mude o rosto e a roupa".
- Textura: as bordas emendam? Tem algum objeto chamando atenção? (não pode)

# Fazer os seus

Todos esses saíram do **Ateliê de arte** do site (menu Preparar). Lá você troca as linhas e gera outros na hora:
- **Folha de sprites**: um sprite por linha, até 16.
- **Tira de animação**: uma linha diz o que se mexe (saem 6 quadros).
- **Textura que repete**: só o material.
- **Puxar do site**: preenche com a ficha do inimigo, NPC ou ilha.
- **Lote**: prompts da luta inteira de uma vez.
